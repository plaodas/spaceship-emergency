# 乗員症状 50件

診断入力の評価用コーパスです。乗員の口語で書いてあります。整備文書側の語彙とは揃えてありません。

種別:

- `single` — 1枚のカードで足りる対照。埋め込みの言い換えは必要で、文書をまたぐ結合は不要。
- `compose` — 2枚以上の故障カードと、1枚以上の結合ノートがないと説明が閉じない。
- `reject` — クエリ中の語が交絡カードを引き寄せる。本命は、否定・時間窓・場所で決まる。

関連: [カード規則](02-card-rules.md) / [デモ診断](05-demo-diagnosis.md)

Q01、Q02、Q16、Q17 のゴールド集合は、予約カードで閉じるデモクラスタです。他の `compose` は、100件を揃えたあとにゴールド集合を付けます。付けるときも、結論を1枚に書いたカードを正解にしてはいけません。

## 評価での扱い

- `compose` の採点は、単一の正解文との一致では行わない。種カードの再現、拡張後に結合ノートが入ること、交絡を本命にしなかったこと、で見る。
- Q12 と Q39 は、デモクラスタの一部だけが該当する。クラスタ全件を必須ゴールドにすると、報告されていない消費増加まで正解扱いになる。
- Q36、Q37、Q38、Q48 は、デモクエリと同じ語を含みながら本命が違う対照である。
